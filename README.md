# Libertas Jyotish — Brand Assets

サイト（PWA）・Etsy・Pinterest・YouTube / Instagram / TikTok で共通に使う元画像と、配色・フォントの指定。
どのチャンネルの作業でも、新しい背景・挿絵・サムネイルを作るときはここの素材とルールを起点にする。

## フォルダ

| フォルダ | 内容 |
|---|---|
| `backgrounds/` | サイト全体の背景（`bg-jyotish.jpg` 星図と神殿）、OGP 画像、鑑定書表紙 |
| `logo/` | ロゴ（横長）、アプリ／ショップアイコン 512px（通常・maskable） |
| `ornaments/` | 曼荼羅（月と太陽・ホイール・黄道十二宮）、地球アイコン SVG。透過 PNG、装飾・区切り用 |
| `illustrations/` | 挿絵。`*-gold.png` は Grok 元画像（`grok_image_*.jpg`、市松模様は擬似透過）から切り出した本物の透過 PNG（黄道十二宮曼荼羅・法輪曼荼羅・蓮＋十二宮・象とロータス）。紺・クリームどちらの背景でも使える |
| `etsy/` | Etsy リスティング画像（出生図・相性・年間・キャリア）、ショップバナー |
| `pinterest/` | Pinterest ピン 1000x1500（商品紹介 18 本＋教育系 edu-01〜05） |
| `banners/` | note / Medium 記事用バナー |
| `generated/` | AI 生成した元画像（背景候補・挿絵候補）。採用前のものもここに置く。系統別の一覧は `generated/INDEX.md` |
| `video/` | SNS ショート動画用の 15 秒ループ背景（`source/`）と完成品の参考（`produced/`）。一覧は `video/INDEX.md`。約 1.1GB あるので画像だけ欲しいときは `git clone --filter=blob:none --sparse` で `video/` を除外可 |
| `scripts/` | 画像を生成した Pillow スクリプト（同じトーンで量産するときに再利用） |

## フォント
- 見出し（欧文）: **Cinzel**（サイト）／FreeSerif Bold（画像生成時の代替）
- 本文（日本語）: **Noto Serif JP**
- 画像内の英文本文: FreeSerif / DejaVu Sans（Pillow で生成）
- アラビア語: Noto Naskh Arabic（RTL）

## トーン
- 高貴・神秘的だが、現実的で温かい。恐怖や断定をあおる表現・ビジュアル（黒、血の赤、髑髏等）は使わない。
- 商品画像はダーク×ゴールド、Pinterest 教育系はクリーム×ティールで統一。混ぜない。
- 宗教画・神像の直接使用は避け、曼荼羅・幾何学・天体・ロータス・象などのモチーフを使う。

## 加工ルール
- 元画像・元動画の加工は自由（トリミング、暗くする・薄くする、ぼかす、半透明パネルを敷く、色調補正）。文字が読めることを優先する。
- 文字パネルは、暗い背景なら黒 55〜65%・白文字、明るい背景なら白 70%・濃茶文字（動画完成品と同じ作法）。

## 使い方（Devin への指示例）
- 「brand-assets の `backgrounds/bg-jyotish.jpg` をベースに YouTube サムネを作って」
- 「`ornaments/mandala-zodiac.png` を透かしで入れて」
- 新しい元画像ができたら `generated/` に日付＋用途のファイル名で追加（例: `2026-09-temple-night.jpg`）
